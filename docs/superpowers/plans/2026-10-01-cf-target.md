# cf-target Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Cloud Foundry command Claude runs for a project goes to the account declared in that project's `.cf-target`, with passwords in Windows Credential Manager, isolated per-run sessions, a global hook that blocks raw `cf`, and two global skills (`cf-target`, `cf-proxy`).

**Architecture:** A dependency-free Node CLI (`cf-target`) reads `.cf-target` (walking up from the cwd), copies the user's shared session (`~/.cf-target/sessions/<api>/<user>/cf-home`) into a temp `CF_HOME`, logs in with the stored password if needed, verifies identity, sets the declared org/space in the copy, runs `cf`, and writes renewed tokens back with compare-and-swap. A PreToolUse hook denies raw `cf`. cf-proxy vendors the same session module so one login serves both.

**Tech Stack:** Node ≥ 18 (CommonJS, no npm dependencies), PowerShell 5.1 + P/Invoke for Credential Manager, Python 3.11 `ctypes` for the launcher, Claude Code hooks/skills.

**Spec:** `docs/superpowers/specs/2026-10-01-cf-target-design.md` (read it first; §7 sessions are keyed by `(api, user)`).

## Global Constraints

- Windows is the target platform; code must not break on POSIX but Credential Manager is Windows-only.
- No npm dependencies. Node ≥ 18. Test files are plain Node scripts (`test/*.test.js`) using `test/helpers.js`; `npm test` runs them all.
- Code, comments, docs of this repo: English. Files under `~/.claude/hooks` follow the existing hooks there (Spanish comments). Skills: English `description`, Spanish body (like `cpi-develop`).
- A password never appears in argv, in stdout/stderr printed to a terminal, in any file outside Credential Manager, or in the chat. It travels only through pipes (stdin of PowerShell / stdout pipe back to Node) and the `CF_PASSWORD` env var of the `cf auth` child.
- `.cf-target` is never committed: `init` adds it to `.gitignore` of git repos.
- Only `--version`, `version`, `help`, `-h`, `--help`, `plugins` (and bare `cf`) pass the hook.
- Exit codes: 0 ok · 1 error · 2 usage / no `.cf-target` · 4 no session · 6 org/space not found · 7 identity mismatch · otherwise `cf`'s own code for `cf-target -- …`.
- Live systems (global CLAUDE.md): registering the hook in `~/.claude/settings.json`, the opt-in global `cf logout`, and anything that writes to BTP need the user's explicit OK at that step. Never commit or push without being asked.
- Test isolation env vars: `CF_TARGET_HOME` (session store + test cred file), `CF_TARGET_CRED_BACKEND=file`, `CF_TARGET_CF_BIN` (fake cf), `CF_TARGET_CLAUDE_DIR` (install target), `FAKE_CF_LOG`.

## Review Focus

1. **Org names with spaces, commas or `&`** (`Acme Inc. S4 Rise , GUI SSO , MBC …`) must reach `cf target -o` as one argument, unmangled — pinned in Task 4 (runner test with that org).
2. **A run killed mid-command (Ctrl+C / taskkill)** must leave the shared session intact and no `session.lock` behind, so the next run works — pinned in Task 5 (kill a slow run, run again).
3. **Passwords with quotes, `%`, `&`, `^`, spaces and non-ASCII** must round-trip through stdin → PowerShell JSON → Credential Manager → `CF_PASSWORD` — pinned in Task 2 (file backend always, Credential Manager opt-in).
4. **Multi-line PowerShell / nested shells** (`powershell -Command "cf apps; …"`, a script whose second line is `cf apps`, a `# cf push` comment line) must be judged per line — pinned in Task 7 hook table.
5. **A real `cf` whose access token expired but refresh token is valid** must just work and the renewed token must reach the shared session — no fake can prove this; pinned in Task 12 live check (`cf-target show` before/after a token-renewing command, compare `AccessToken` hash of the shared config).

- [ ] **Step 4: Implement** `lib/targetfile.js`
```js
"use strict";
/**
 * The .cf-target file: which Cloud Foundry account a project uses.
 *
 * Plain "key = value" lines so the user can read it at a glance. It never holds
 * a password: those live in Windows Credential Manager (credstore.js).
 */
const fs = require("fs");
const path = require("path");

const FILE_NAME = ".cf-target";
const REQUIRED = ["api", "org", "space", "user", "auth"];
const OPTIONAL = ["origin"];
const AUTH_VALUES = ["password", "sso"];

/** Same endpoint written differently (case, trailing slash) is the same region. */
function normalizeApi(api) {
	return String(api || "").trim().replace(/\/+$/, "").toLowerCase();
}

function parseTarget(text, file = FILE_NAME) {
	const out = {};
	String(text).split(/\r?\n/).forEach((raw, i) => {
		const where = `${file}:${i + 1}`;
		// An inline comment needs whitespace before "#", so a "#" inside a value survives.
		const line = raw.replace(/\s+#.*$/, "").trim();
		if (!line || line.startsWith("#")) return;
		const eq = line.indexOf("=");
		if (eq === -1) throw new Error(`${where}: expected "key = value"`);
		const key = line.slice(0, eq).trim();
		const value = line.slice(eq + 1).trim();
		if (!REQUIRED.includes(key) && !OPTIONAL.includes(key)) throw new Error(`${where}: unknown key "${key}"`);
		if (key in out) throw new Error(`${where}: duplicate key "${key}"`);
		if (!value) throw new Error(`${where}: empty value for "${key}"`);
		out[key] = value;
	});
	for (const key of REQUIRED) {
		if (!out[key]) throw new Error(`${file}: missing "${key}"`);
	}
	if (!AUTH_VALUES.includes(out.auth)) {
		throw new Error(`${file}: auth must be ${AUTH_VALUES.join(" or ")}`);
	}
	return out;
}

/** Nearest .cf-target from startDir upward, the way git finds .git. */
function findTargetFile(startDir) {
	let dir = path.resolve(startDir);
	for (;;) {
		const candidate = path.join(dir, FILE_NAME);
		if (fs.existsSync(candidate)) return candidate;
		const parent = path.dirname(dir);
		if (parent === dir) return null;
		dir = parent;
	}
}

function loadTarget(startDir) {
	const file = findTargetFile(startDir);
	if (!file) return null;
	return { file, dir: path.dirname(file), target: parseTarget(fs.readFileSync(file, "utf8"), file) };
}

function formatTarget(target) {
	const keys = [...REQUIRED, ...OPTIONAL].filter((k) => target[k]);
	const width = Math.max(...keys.map((k) => k.length));
	return [
		"# Cloud Foundry account for this project. Used by cf-target, cf-proxy and Claude.",
		"# Not committed (.gitignore). Passwords are NOT here: Windows Credential Manager.",
		...keys.map((k) => `${k.padEnd(width)} = ${target[k]}`),
		""
	].join("\n");
}

function writeTarget(dir, target) {
	const file = path.join(dir, FILE_NAME);
	fs.writeFileSync(file, formatTarget(target), "utf8");
	return file;
}

/** Adds .cf-target to the .gitignore of a git repo. Returns true if it added the line. */
function ensureGitignored(dir) {
	if (!fs.existsSync(path.join(dir, ".git"))) return false;
	const file = path.join(dir, ".gitignore");
	const current = fs.existsSync(file) ? fs.readFileSync(file, "utf8") : "";
	const lines = current.split(/\r?\n/).map((l) => l.trim());
	if (lines.includes(FILE_NAME) || lines.includes(`/${FILE_NAME}`)) return false;
	const sep = current && !current.endsWith("\n") ? "\n" : "";
	fs.writeFileSync(file, `${current}${sep}${FILE_NAME}\n`, "utf8");
	return true;
}

module.exports = {
	FILE_NAME, REQUIRED, AUTH_VALUES, normalizeApi, parseTarget,
	findTargetFile, loadTarget, formatTarget, writeTarget, ensureGitignored
};
```

```js
"use strict";
/**
 * Passwords, one per (API endpoint, user), in Windows Credential Manager.
 *
 * Visible to the user in Control Panel > Credential Manager > Windows
 * Credentials, entry "cf-target:<api>:<user>". Shared by every project and by
 * cf-proxy's launcher (same key).
 *
 * The secret never goes through argv: PowerShell receives the request as JSON
 * on stdin and answers through a pipe. Node's built-ins cannot call advapi32
 * directly, hence PowerShell + P/Invoke (~300 ms per call).
 *
 * CF_TARGET_CRED_BACKEND=file stores into $CF_TARGET_HOME/credentials.test.json
 * instead: tests only, never for real use.
 */
const fs = require("fs");
const path = require("path");
const { spawnSync } = require("child_process");
const { normalizeApi } = require("./targetfile");
const { baseDir } = require("./sessions");

const PS_SCRIPT = String.raw`
$ErrorActionPreference = 'Stop'
Add-Type -TypeDefinition @'
using System;
using System.Runtime.InteropServices;
using System.Text;
public static class CfTargetCred {
  [StructLayout(LayoutKind.Sequential, CharSet = CharSet.Unicode)]
  public struct CREDENTIAL {
    public int Flags; public int Type; public string TargetName; public string Comment;
    public long LastWritten; public int CredentialBlobSize; public IntPtr CredentialBlob;
    public int Persist; public int AttributeCount; public IntPtr Attributes;
    public string TargetAlias; public string UserName;
  }
  [DllImport("advapi32.dll", CharSet = CharSet.Unicode, SetLastError = true)] static extern bool CredWrite(ref CREDENTIAL c, int flags);
  [DllImport("advapi32.dll", CharSet = CharSet.Unicode, SetLastError = true)] static extern bool CredRead(string target, int type, int flags, out IntPtr c);
  [DllImport("advapi32.dll", CharSet = CharSet.Unicode, SetLastError = true)] static extern bool CredDelete(string target, int type, int flags);
  [DllImport("advapi32.dll")] static extern void CredFree(IntPtr p);
  public static void Write(string target, string user, string secret) {
    byte[] blob = Encoding.Unicode.GetBytes(secret);
    var c = new CREDENTIAL { Type = 1, TargetName = target, UserName = user, CredentialBlobSize = blob.Length, CredentialBlob = Marshal.AllocCoTaskMem(blob.Length), Persist = 2 };
    try {
      Marshal.Copy(blob, 0, c.CredentialBlob, blob.Length);
      if (!CredWrite(ref c, 0)) throw new Exception("CredWrite failed: " + Marshal.GetLastWin32Error());
    } finally { Marshal.FreeCoTaskMem(c.CredentialBlob); }
  }
  public static string Read(string target) {
    IntPtr p;
    if (!CredRead(target, 1, 0, out p)) return null;
    try {
      var c = (CREDENTIAL)Marshal.PtrToStructure(p, typeof(CREDENTIAL));
      return Marshal.PtrToStringUni(c.CredentialBlob, c.CredentialBlobSize / 2);
    } finally { CredFree(p); }
  }
  public static bool Delete(string target) { return CredDelete(target, 1, 0); }
}
'@
$req = [Console]::In.ReadToEnd() | ConvertFrom-Json
switch ($req.op) {
  'get'    { $s = [CfTargetCred]::Read($req.target); if ($null -eq $s) { '{"found":false}' } else { @{ found = $true; secret = $s } | ConvertTo-Json -Compress } }
  'set'    { [CfTargetCred]::Write($req.target, $req.user, $req.secret); '{"ok":true}' }
  'delete' { @{ ok = $true; deleted = [CfTargetCred]::Delete($req.target) } | ConvertTo-Json -Compress }
}
`;

function backend() {
	return process.env.CF_TARGET_CRED_BACKEND === "file" ? "file" : "wincred";
}

function credKey(api, user) {
	return `cf-target:${normalizeApi(api)}:${String(user || "").trim().toLowerCase()}`;
}

function powershell(request) {
	// -EncodedCommand: the script travels as base64 UTF-16LE, no quoting issues.
	const encoded = Buffer.from(PS_SCRIPT, "utf16le").toString("base64");
	const r = spawnSync("powershell.exe",
		["-NoProfile", "-NonInteractive", "-ExecutionPolicy", "Bypass", "-EncodedCommand", encoded],
		{ input: JSON.stringify(request), encoding: "utf8", windowsHide: true, timeout: 30000 });
	const last = String(r.stdout || "").trim().split(/\r?\n/).pop();
	try {
		return JSON.parse(last);
	} catch (e) {
		const why = String(r.stderr || (r.error && r.error.message) || "no output").trim().split(/\r?\n/)[0];
		throw new Error(`Windows Credential Manager: ${why}`);
	}
}

function testFile() {
	return path.join(baseDir(), "credentials.test.json");
}

function readTestStore() {
	try { return JSON.parse(fs.readFileSync(testFile(), "utf8")); } catch (e) { return {}; }
}

function writeTestStore(store) {
	fs.mkdirSync(path.dirname(testFile()), { recursive: true });
	fs.writeFileSync(testFile(), JSON.stringify(store, null, 2), "utf8");
}

function getPassword(api, user) {
	const key = credKey(api, user);
	if (backend() === "file") return readTestStore()[key] ?? null;
	const res = powershell({ op: "get", target: key });
	return res.found ? res.secret : null;
}

function setPassword(api, user, secret) {
	const key = credKey(api, user);
	if (backend() === "file") {
		const store = readTestStore();
		store[key] = secret;
		return writeTestStore(store);
	}
	powershell({ op: "set", target: key, user: String(user).trim(), secret });
}

function deletePassword(api, user) {
	const key = credKey(api, user);
	if (backend() === "file") {
		const store = readTestStore();
		if (!(key in store)) return false;
		delete store[key];
		writeTestStore(store);
		return true;
	}
	return Boolean(powershell({ op: "delete", target: key }).deleted);
}

module.exports = { backend, credKey, getPassword, setPassword, deletePassword };
```

```js
"use strict";
/**
 * Cloud Foundry sessions: one per (API endpoint, user), shared by cf-target and
 * cf-proxy, and a private copy for every run.
 *
 * Why a copy: cf keeps the session AND the target (org/space) in one
 * config.json. Sharing it would make two repos fight over the target, and two
 * cf processes writing it at once is how ~/.cf ends up with corrupt_* backups.
 * Each run works on a temp copy and sets its own target there; only renewed
 * tokens go back, with compare-and-swap, so a concurrent refresh is never lost
 * or half-written.
 *
 * Vendored verbatim into CF-proxy (lib/sessions.js): keep it free of requires
 * outside Node's standard library. test/vendored.test.js checks the copies match.
 */
const crypto = require("crypto");
const fs = require("fs");
const os = require("os");
const path = require("path");

const TOKEN_FIELDS = ["AccessToken", "RefreshToken", "UAAGrantType"];
const LOCK_STALE_MS = 30000;
const LOCK_WAIT_MS = 10000;

function baseDir() {
	return process.env.CF_TARGET_HOME || path.join(os.homedir(), ".cf-target");
}

function normalizeApi(api) {
	return String(api || "").trim().replace(/\/+$/, "").toLowerCase();
}

/** Readable, filesystem-safe and collision-free: "dev_acme.com-1a2b3c4d". */
function slug(value) {
	const raw = String(value || "").trim().toLowerCase();
	const clean = raw.replace(/[^a-z0-9._-]+/g, "_").replace(/^_+|_+$/g, "").slice(0, 40) || "_";
	return `${clean}-${crypto.createHash("sha256").update(raw).digest("hex").slice(0, 8)}`;
}

function sessionHome(api, user) {
	let host;
	try {
		host = new URL(normalizeApi(api)).host;
	} catch (e) {
		host = normalizeApi(api);
	}
	return path.join(baseDir(), "sessions", slug(host), slug(user), "cf-home");
}

function configFile(home) {
	return path.join(home, ".cf", "config.json");
}

function hashFile(file) {
	try {
		return crypto.createHash("sha256").update(fs.readFileSync(file)).digest("hex");
	} catch (e) {
		return null;
	}
}

function sleep(ms) {
	Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, ms);
}

/** Short exclusive lock on a session, held only while copying or writing back. */
function lock(sharedHome) {
	const file = path.join(path.dirname(sharedHome), "session.lock");
	fs.mkdirSync(path.dirname(file), { recursive: true });
	const deadline = Date.now() + LOCK_WAIT_MS;
	for (;;) {
		try {
			fs.closeSync(fs.openSync(file, "wx"));
			return () => {
				try { fs.unlinkSync(file); } catch (e) { /* already gone */ }
			};
		} catch (e) {
			if (e.code !== "EEXIST") throw e;
			try {
				// A lock older than any copy could take belongs to a dead process.
				if (Date.now() - fs.statSync(file).mtimeMs > LOCK_STALE_MS) {
					fs.unlinkSync(file);
					continue;
				}
			} catch (_) {
				continue;
			}
			if (Date.now() > deadline) throw new Error(`Session busy: ${file}`);
			sleep(50);
		}
	}
}

function writeAtomic(file, text) {
	fs.mkdirSync(path.dirname(file), { recursive: true });
	const tmp = `${file}.${process.pid}.${Date.now()}.tmp`;
	fs.writeFileSync(tmp, text, "utf8");
	fs.renameSync(tmp, file);
}

/** Private CF_HOME for one run: a copy of the shared session (or empty). */
function openRun(sharedHome) {
	const home = fs.mkdtempSync(path.join(os.tmpdir(), "cf-target-"));
	const release = lock(sharedHome);
	try {
		const shared = configFile(sharedHome);
		if (fs.existsSync(shared)) {
			fs.mkdirSync(path.dirname(configFile(home)), { recursive: true });
			fs.copyFileSync(shared, configFile(home));
		}
		return { home, sharedHome, baseHash: hashFile(shared) };
	} finally {
		release();
	}
}

/**
 * Copies renewed tokens back to the shared session.
 * replace: true (after a login) writes the whole config.
 * Returns "written", "unchanged", or "skipped" (another run wrote first: theirs wins).
 */
function writeBack(run, { replace = false } = {}) {
	let mine;
	try {
		mine = JSON.parse(fs.readFileSync(configFile(run.home), "utf8"));
	} catch (e) {
		return "unchanged";
	}
	const sharedFile = configFile(run.sharedHome);
	const release = lock(run.sharedHome);
	try {
		const current = hashFile(sharedFile);
		if (replace || current === null) {
			writeAtomic(sharedFile, JSON.stringify(mine, null, 2));
			return "written";
		}
		const shared = JSON.parse(fs.readFileSync(sharedFile, "utf8"));
		if (TOKEN_FIELDS.every((k) => shared[k] === mine[k])) return "unchanged";
		if (current !== run.baseHash) return "skipped";
		for (const k of TOKEN_FIELDS) shared[k] = mine[k];
		writeAtomic(sharedFile, JSON.stringify(shared, null, 2));
		return "written";
	} finally {
		release();
	}
}

function closeRun(run) {
	fs.rmSync(run.home, { recursive: true, force: true });
}

module.exports = { TOKEN_FIELDS, baseDir, normalizeApi, sessionHome, configFile, openRun, writeBack, closeRun };
```

```js
"use strict";
/**
 * The only place that executes `cf`. Always with an explicit CF_HOME: there is
 * no code path that touches the global ~/.cf session.
 */
const os = require("os");
const { execFile, spawn } = require("child_process");

const CF_BIN = process.env.CF_TARGET_CF_BIN || (process.platform === "win32" ? "cf.exe" : "cf");

/** A .js CF_BIN (the tests' fake cf) runs with node. */
function command(args) {
	return CF_BIN.endsWith(".js") ? [process.execPath, [CF_BIN, ...args]] : [CF_BIN, args];
}

/** CF_PLUGIN_HOME keeps plugins (multiapps) coming from ~/.cf while the session is private. */
function cfEnv(home, extra = {}) {
	return { ...process.env, CF_HOME: home, CF_PLUGIN_HOME: process.env.CF_PLUGIN_HOME || os.homedir(), ...extra };
}

function cfCapture(args, { home, env = {}, timeout = 120000 } = {}) {
	if (!home) throw new Error("cfCapture needs a CF_HOME");
	return new Promise((resolve) => {
		const [bin, argv] = command(args);
		// No shell: arguments (org names with spaces, "&", commas) reach cf untouched.
		const child = execFile(bin, argv, { env: cfEnv(home, env), timeout, windowsHide: true, maxBuffer: 32 * 1024 * 1024 }, (err, stdout, stderr) => {
			const code = !err ? 0 : typeof err.code === "number" ? err.code : err.code === "ENOENT" ? 127 : 1;
			resolve({ code, out: String(stdout || ""), err: String(stderr || "") });
		});
		// A cf prompt (e.g. "select an org") gets EOF instead of hanging until the timeout.
		child.stdin.end();
	});
}

function cfInherit(args, { home }) {
	if (!home) throw new Error("cfInherit needs a CF_HOME");
	return new Promise((resolve) => {
		const [bin, argv] = command(args);
		const child = spawn(bin, argv, { env: cfEnv(home), stdio: "inherit", windowsHide: true });
		child.on("error", () => resolve(127));
		child.on("exit", (code) => resolve(code === null ? 1 : code));
	});
}

/** Fields of `cf target`. [ \t]* (not \s*) so an empty value does not swallow the next line. */
function parseTargetOutput(out) {
	const field = (label) => {
		const m = String(out).match(new RegExp(`^${label}:[ \\t]*(.*)$`, "im"));
		const value = m ? m[1].trim() : "";
		return value || null;
	};
	return { api: field("API endpoint"), user: field("user"), org: field("org"), space: field("space") };
}

function lastLines(result, n = 3) {
	return `${result.err}\n${result.out}`.trim().split(/\r?\n/).filter(Boolean).slice(-n).join(" ");
}

module.exports = { cfEnv, cfCapture, cfInherit, parseTargetOutput, lastLines };
```

```js
"use strict";
/**
 * Puts a private CF_HOME in the state a .cf-target asks for, or says why it
 * cannot: session (logging in with the stored password if needed), identity
 * (the session's user and API are the file's), and target (org/space).
 */
const { cfCapture, parseTargetOutput, lastLines } = require("./cfexec");
const credstore = require("./credstore");
const { normalizeApi } = require("./targetfile");

const EXIT = { ERROR: 1, USAGE: 2, NO_SESSION: 4, NO_TARGET: 6, MISMATCH: 7 };
const LOGIN_HINT = "Run in your terminal: cf-target login";

async function sessionOf(home) {
	const r = await cfCapture(["target"], { home, timeout: 60000 });
	if (r.code !== 0) return null;
	const s = parseTargetOutput(r.out);
	return s.user ? s : null;
}

function sameIdentity(session, target) {
	return normalizeApi(session.api) === normalizeApi(target.api) &&
		String(session.user).toLowerCase() === String(target.user).toLowerCase();
}

/** cf auth with the password in the environment: it never shows up in argv. */
async function passwordLogin(target, home, password) {
	const api = await cfCapture(["api", target.api], { home, timeout: 60000 });
	if (api.code !== 0) return { ok: false, error: lastLines(api) };
	const args = ["auth"];
	if (target.origin) args.push("--origin", target.origin);
	const auth = await cfCapture(args, { home, env: { CF_USERNAME: target.user, CF_PASSWORD: password }, timeout: 120000 });
	return auth.code === 0 ? { ok: true } : { ok: false, error: lastLines(auth) || "Credentials rejected." };
}

async function ssoLogin(target, home, passcode) {
	const r = await cfCapture(["login", "-a", target.api, "--sso-passcode", passcode], { home, timeout: 120000 });
	return r.code === 0 ? { ok: true } : { ok: false, error: lastLines(r) || "Passcode rejected." };
}

async function ensureSession(target, home) {
	let session = await sessionOf(home);
	if (!session || !sameIdentity(session, target)) {
		if (target.auth !== "password") {
			return { ok: false, code: EXIT.NO_SESSION, error: `No valid cf session for ${target.user} (SSO: needs a passcode).`, hint: LOGIN_HINT };
		}
		const password = credstore.getPassword(target.api, target.user);
		if (!password) {
			return { ok: false, code: EXIT.NO_SESSION, error: `No cf session and no stored password for ${target.user} on ${target.api}.`, hint: LOGIN_HINT };
		}
		const login = await passwordLogin(target, home, password);
		if (!login.ok) {
			return { ok: false, code: EXIT.NO_SESSION, error: `Automatic login failed: ${login.error}`, hint: `Check the stored password. ${LOGIN_HINT}` };
		}
		session = await sessionOf(home);
		if (!session) return { ok: false, code: EXIT.NO_SESSION, error: "Login did not leave a session.", hint: LOGIN_HINT };
	}
	if (!sameIdentity(session, target)) {
		return { ok: false, code: EXIT.MISMATCH, error: `Session is ${session.user} on ${session.api}; .cf-target says ${target.user} on ${target.api}.` };
	}
	return { ok: true, session };
}

async function prepare(target, home) {
	const s = await ensureSession(target, home);
	if (!s.ok) return s;
	const t = await cfCapture(["target", "-o", target.org, "-s", target.space], { home, timeout: 60000 });
	if (t.code !== 0) {
		return { ok: false, code: EXIT.NO_TARGET, error: `Cannot target ${target.org} / ${target.space}: ${lastLines(t)}` };
	}
	return { ok: true, session: { api: s.session.api, user: s.session.user, org: target.org, space: target.space } };
}

module.exports = { EXIT, sessionOf, sameIdentity, passwordLogin, ssoLogin, ensureSession, prepare };
```

```js
#!/usr/bin/env node
"use strict";
/**
 * cf-target - run Cloud Foundry commands only against the account declared in
 * this project's .cf-target.
 *
 *   cf-target -- <cf args>      run cf against this folder's account
 *   cf-target show              which account this folder uses, password stored?, session?
 *   cf-target login             log in (password: prompted, stored in Credential Manager)
 *                               [--password-stdin | --sso-passcode X]
 *   cf-target forget            delete the stored password
 *   cf-target init ...          create .cf-target (see Task 6)
 *   cf-target targets ...       orgs/spaces the user can see (see Task 6)
 *
 * --json: one JSON object per command. Exit codes: 0 ok, 1 error, 2 usage or no
 * .cf-target, 4 no session, 6 org/space not found, 7 identity mismatch;
 * `cf-target -- ...` returns cf's own exit code.
 */
const readline = require("readline");
const tf = require("../lib/targetfile");
const sessions = require("../lib/sessions");
const credstore = require("../lib/credstore");
const { cfInherit } = require("../lib/cfexec");
const runner = require("../lib/runner");
const { EXIT } = runner;

// ---------------------------------------------------------------------------
// Arguments: own flags before `--`, cf's arguments after it, untouched.
// ---------------------------------------------------------------------------
const argv = process.argv.slice(2);
const dashdash = argv.indexOf("--");
const own = dashdash === -1 ? argv : argv.slice(0, dashdash);
const rest = dashdash === -1 ? [] : argv.slice(dashdash + 1);
const positional = [];
const flags = {};
for (let i = 0; i < own.length; i++) {
	const a = own[i];
	if (a.startsWith("--")) {
		const next = own[i + 1];
		if (next !== undefined && !next.startsWith("--")) {
			flags[a.slice(2)] = next;
			i++;
		} else {
			flags[a.slice(2)] = true;
		}
	} else {
		positional.push(a);
	}
}
const JSON_OUT = flags.json === true;

function done(payload, human) {
	if (JSON_OUT) console.log(JSON.stringify({ ok: true, ...payload }));
	else if (human) human();
	process.exit(0);
}

function die(code, error, extra = {}) {
	if (JSON_OUT) {
		console.log(JSON.stringify({ ok: false, code, error, ...extra }));
	} else {
		console.error(`cf-target: ${error}`);
		if (extra.hint) console.error(extra.hint);
	}
	process.exit(code);
}

function readStdin() {
	return new Promise((resolve) => {
		let data = "";
		process.stdin.setEncoding("utf8");
		process.stdin.on("data", (c) => (data += c));
		process.stdin.on("end", () => resolve(data));
	});
}

/** Prompt without echo: the password is typed by the user, never shown or logged. */
function promptHidden(question) {
	return new Promise((resolve) => {
		const rl = readline.createInterface({ input: process.stdin, output: process.stdout, terminal: true });
		rl._writeToOutput = (s) => {
			if (s.startsWith(question)) process.stdout.write(question);
		};
		rl.question(question, (answer) => {
			rl.close();
			process.stdout.write("\n");
			resolve(answer);
		});
	});
}

function requireTarget() {
	let loaded;
	try {
		loaded = tf.loadTarget(process.cwd());
	} catch (e) {
		die(EXIT.USAGE, e.message);
	}
	if (!loaded) {
		die(EXIT.USAGE, "No .cf-target in this folder or its parents: this project has no declared Cloud Foundry account.",
			{ hint: "Create it: cf-target init --api <url> --org <org> --space <space> --user <user> --auth password|sso" });
	}
	return loaded;
}

/**
 * Runs fn(home) on a private copy of the user's session and writes renewed
 * tokens back. replaceOnSuccess (login): the whole config replaces the shared one.
 */
async function withRun(target, fn, { replaceOnSuccess = false } = {}) {
	const run = sessions.openRun(sessions.sessionHome(target.api, target.user));
	try {
		const result = await fn(run.home);
		sessions.writeBack(run, { replace: replaceOnSuccess && Boolean(result && result.ok) });
		return result;
	} finally {
		sessions.closeRun(run);
	}
}

// ---------------------------------------------------------------------------
// cf-target -- <args>
// ---------------------------------------------------------------------------
async function cmdRun() {
	if (!rest.length) die(EXIT.USAGE, "Missing cf arguments after --.", { hint: "Example: cf-target -- apps" });
	const { target } = requireTarget();
	const result = await withRun(target, async (home) => {
		const prep = await runner.prepare(target, home);
		if (!prep.ok) return prep;
		// stderr, so piping cf's output stays clean.
		process.stderr.write(`[cf-target] ${target.api} / ${target.org} / ${target.space} as ${prep.session.user}\n`);
		return { ok: true, exitCode: await cfInherit(rest, { home }) };
	});
	if (!result.ok) die(result.code, result.error, { hint: result.hint });
	process.exit(result.exitCode);
}

// ---------------------------------------------------------------------------
// show
// ---------------------------------------------------------------------------
async function cmdShow() {
	const { file, target } = requireTarget();
	const passwordStored = target.auth === "password" && Boolean(credstore.getPassword(target.api, target.user));
	const { session } = await withRun(target, async (home) => ({ ok: true, session: await runner.sessionOf(home) }));
	const state = !session ? "none" : runner.sameIdentity(session, target) ? "ok" : `other user (${session.user})`;
	done({ file, target, passwordStored, session: state }, () => {
		console.log(`.cf-target  ${file}`);
		console.log(`account     ${target.api} / ${target.org} / ${target.space}`);
		console.log(`user        ${target.user} (${target.auth}${target.auth === "password" ? `, password stored: ${passwordStored ? "yes" : "no"}` : ""})`);
		console.log(`session     ${state}`);
	});
}

// ---------------------------------------------------------------------------
// login / forget
// ---------------------------------------------------------------------------
async function cmdLogin() {
	const { target } = requireTarget();
	let attempt;
	if (target.auth === "sso") {
		if (typeof flags["sso-passcode"] === "string") {
			attempt = (home) => runner.ssoLogin(target, home, flags["sso-passcode"]);
		} else if (process.stdin.isTTY) {
			attempt = async (home) => ({ ok: (await cfInherit(["login", "-a", target.api, "--sso"], { home })) === 0, error: "cf login --sso failed." });
		} else {
			die(EXIT.USAGE, "SSO login needs a terminal or --sso-passcode.", { hint: "Run in your terminal: cf-target login" });
		}
	} else {
		let password;
		if (flags["password-stdin"]) password = (await readStdin()).replace(/\r?\n$/, "");
		else if (process.stdin.isTTY) password = await promptHidden(`Password for ${target.user} (${target.api}): `);
		else die(EXIT.USAGE, "Password login needs a terminal or --password-stdin.", { hint: "Run in your terminal: cf-target login" });
		if (!password) die(EXIT.USAGE, "Empty password.");
		attempt = async (home) => {
			const r = await runner.passwordLogin(target, home, password);
			// Stored only after cf accepted it.
			if (r.ok) credstore.setPassword(target.api, target.user, password);
			return r;
		};
	}

	const result = await withRun(target, async (home) => {
		const r = await attempt(home);
		if (!r.ok) return { ok: false, code: EXIT.NO_SESSION, error: r.error };
		const s = await runner.sessionOf(home);
		if (!s || !runner.sameIdentity(s, target)) {
			return { ok: false, code: EXIT.MISMATCH, error: `Logged in as ${s ? s.user : "?"}, but .cf-target says ${target.user}.` };
		}
		return { ok: true, user: s.user };
	}, { replaceOnSuccess: true });

	if (!result.ok) die(result.code, result.error);
	done({ user: result.user, api: target.api, passwordStored: target.auth === "password" }, () =>
		console.log(`OK  ${result.user} on ${target.api}${target.auth === "password" ? " (password stored in Windows Credential Manager)" : ""}`));
}

async function cmdForget() {
	const { target } = requireTarget();
	const deleted = credstore.deletePassword(target.api, target.user);
	done({ deleted }, () => console.log(deleted ? `Password for ${target.user} deleted.` : "No stored password."));
}

// ---------------------------------------------------------------------------
const COMMANDS = { show: cmdShow, login: cmdLogin, forget: cmdForget };

if (dashdash !== -1 && !positional.length) {
	cmdRun().catch((e) => die(EXIT.ERROR, e.message));
} else if (COMMANDS[positional[0]]) {
	COMMANDS[positional[0]]().catch((e) => die(EXIT.ERROR, e.message));
} else {
	const doc = require("fs").readFileSync(__filename, "utf8").match(/\/\*\*([\s\S]*?)\*\//)[1].replace(/^ \* ?/gm, "");
	console.log(doc.trim());
	process.exit(positional[0] ? EXIT.USAGE : 0);
}
```

```js
	while (url) {
		const r = await cfCapture(["curl", url], { home, timeout: 60000 });
```

```js
#!/usr/bin/env node
// PreToolUse hook (Bash | PowerShell) — guardia de cuenta de Cloud Foundry.
//
// `cf` guarda UNA sesión y UN target para toda la máquina (~/.cf). Un `cf` suelto
// de Claude va a donde haya quedado el último `cf target`, que puede ser otro
// cliente (ya pasó: un deploy cayó en la subcuenta equivocada). Este hook bloquea todo `cf` directo y manda
// a usar `cf-target -- <args>`, que corre contra la cuenta del `.cf-target` del
// proyecto con una sesión aislada.
//
// Pasa lo que no toca ninguna cuenta: --version, version, help, -h, plugins.
// Límite: no ve un `cf` que corre adentro de otro programa (npm run, mbt, scripts).
// Falla ABIERTO: ante un error propio deja pasar y avisa por stderr.
// Fuente: repo cf-target, global/hooks/cf-guard.js (se instala con scripts/install.js).

const fs = require("fs");
const path = require("path");

const SAFE = new Set(["--version", "-v", "version", "help", "-h", "--help", "plugins"]);
// Shells anidados: el comando real va adentro de un string.
const NESTED = /^(?:cmd(?:\.exe)?\s+\/[ck]|(?:powershell|pwsh)(?:\.exe)?\s+(?:-\w+\s+)*?-c(?:ommand)?|(?:ba|z)?sh\s+-c)\s+(.+)$/is;

function allow() { process.exit(0); }
function deny(reason) {
	process.stdout.write(JSON.stringify({
		hookSpecificOutput: { hookEventName: "PreToolUse", permissionDecision: "deny", permissionDecisionReason: reason }
	}));
	process.exit(0);
}

function stripQuotes(s) {
	return s.trim().replace(/^["']/, "").replace(/["']$/, "");
}

/** Primer segmento que corre `cf` con algo que no está en SAFE, o null. */
function findRawCf(command, depth = 0) {
	for (const seg of command.split(/&&|\|\||;|\||\r?\n/).map((s) => s.trim()).filter(Boolean)) {
		const nested = seg.match(NESTED);
		if (nested && depth < 3) {
			const hit = findRawCf(stripQuotes(nested[1]), depth + 1);
			if (hit) return hit;
			continue;
		}
		const s = seg.replace(/^&\s*/, "").replace(/^(?:[A-Za-z_][A-Za-z0-9_]*=\S*\s+)+/, "");
		const m = s.match(/^(?:"([^"]+)"|'([^']+)'|(\S+))\s*(.*)$/s);
		if (!m) continue;
		const exe = path.win32.basename((m[1] || m[2] || m[3]).replace(/\//g, "\\")).toLowerCase();
		if (!/^cf(?:7|8)?(?:\.exe)?$/.test(exe)) continue;
		const first = (m[4].trim().split(/\s+/)[0] || "").toLowerCase();
		if (!first || SAFE.has(first)) continue;
		return { segment: seg, args: m[4].trim() };
	}
	return null;
}

function findTargetFile(dir) {
	let d = path.resolve(dir);
	for (;;) {
		const f = path.join(d, ".cf-target");
		if (fs.existsSync(f)) return f;
		const parent = path.dirname(d);
		if (parent === d) return null;
		d = parent;
	}
}

function describe(file) {
	const text = fs.readFileSync(file, "utf8");
	const get = (k) => {
		const m = text.match(new RegExp(`^[ \\t]*${k}[ \\t]*=[ \\t]*(.*?)(?:[ \\t]+#.*)?[ \\t]*$`, "m"));
		return m ? m[1] : "?";
	};
	return `${get("api")} / ${get("org")} / ${get("space")}`;
}

function main(data) {
	if (!["Bash", "PowerShell"].includes(data.tool_name)) allow();
	const command = (data.tool_input && data.tool_input.command) || "";
	const hit = findRawCf(command);
	if (!hit) allow();
	const file = findTargetFile(data.cwd || process.cwd());
	if (file) {
		deny(`\`cf\` directo está bloqueado: usaría la sesión global, que puede apuntar a otro cliente. ` +
			`Corré \`cf-target -- ${hit.args}\` (cuenta del proyecto: ${describe(file)}).`);
	}
	deny("`cf` directo está bloqueado y este proyecto no tiene `.cf-target`: no hay cuenta de Cloud Foundry declarada. " +
		"Proponé crearla con `cf-target init` (skill cf-target) y esperá la confirmación del usuario.");
}

let input = "";
process.stdin.on("data", (d) => (input += d));
process.stdin.on("end", () => {
	try {
		main(JSON.parse(input || "{}"));
	} catch (e) {
		process.stderr.write(`cf-guard: ${e && e.message}\n`);
		allow();
	}
});
```

````markdown
# cf-target — la cuenta de Cloud Foundry de cada proyecto

Cada proyecto declara su cuenta en un archivo `.cf-target` en su raíz (gitignored):

```ini

correr nada. Dos repos pueden deployar a la vez, cada uno a su cuenta.

## Regla

**Nunca `cf` directo.** El hook `cf-guard` lo bloquea igual. Todo comando de CF va así:

```
cf-target -- <args de cf>        ej.: cf-target -- deploy mta_archives/app_1.0.0.mtar -f
````

```python
"""
PASO 1 - Contrasenas guardadas, en el Administrador de credenciales de Windows.

Una por (API endpoint, usuario), con la misma clave que usa cf-target
(`cf-target:<api>:<usuario>`): la contrasena que se guarda aca sirve para los
deploys de cualquier proyecto con ese usuario, y al reves. Se ve y se borra en
Panel de control > Administrador de credenciales > Credenciales de Windows.

Se usa advapi32 por ctypes para no agregar dependencias al build. La
contrasena nunca va a un archivo ni a una linea de comandos.

Antes las contrasenas iban en secrets.bin (DPAPI) con clave = nombre de
perfil; migrate_legacy() las pasa una sola vez.
"""
import ctypes
import ctypes.wintypes as wt
import json
import os
from pathlib import Path

APP_DIR = Path(os.environ.get("APPDATA", Path.home())) / "cf-proxy-launcher"
LEGACY_FILE = APP_DIR / "secrets.bin"

CRED_TYPE_GENERIC = 1
CRED_PERSIST_LOCAL_MACHINE = 2


class _CREDENTIAL(ctypes.Structure):
    _fields_ = [("Flags", wt.DWORD), ("Type", wt.DWORD), ("TargetName", wt.LPWSTR),
                ("Comment", wt.LPWSTR), ("LastWritten", wt.FILETIME),
                ("CredentialBlobSize", wt.DWORD), ("CredentialBlob", ctypes.POINTER(ctypes.c_char)),
                ("Persist", wt.DWORD), ("AttributeCount", wt.DWORD), ("Attributes", ctypes.c_void_p),
                ("TargetAlias", wt.LPWSTR), ("UserName", wt.LPWSTR)]


_advapi = ctypes.WinDLL("advapi32", use_last_error=True)
_advapi.CredReadW.argtypes = [wt.LPCWSTR, wt.DWORD, wt.DWORD, ctypes.POINTER(ctypes.POINTER(_CREDENTIAL))]
_advapi.CredReadW.restype = wt.BOOL
_advapi.CredWriteW.argtypes = [ctypes.POINTER(_CREDENTIAL), wt.DWORD]
_advapi.CredWriteW.restype = wt.BOOL
_advapi.CredDeleteW.argtypes = [wt.LPCWSTR, wt.DWORD, wt.DWORD]
_advapi.CredDeleteW.restype = wt.BOOL
_advapi.CredFree.argtypes = [ctypes.c_void_p]


def _normalize_api(api: str) -> str:
    return str(api or "").strip().rstrip("/").lower()


def cred_key(api: str, user: str) -> str:
    return f"cf-target:{_normalize_api(api)}:{str(user or '').strip().lower()}"


def get_password(api: str, user: str) -> str:
    """La contrasena guardada, o '' si no hay."""
    pcred = ctypes.POINTER(_CREDENTIAL)()
    if not _advapi.CredReadW(cred_key(api, user), CRED_TYPE_GENERIC, 0, ctypes.byref(pcred)):
        return ""
    try:
        c = pcred.contents
        return ctypes.string_at(c.CredentialBlob, c.CredentialBlobSize).decode("utf-16-le")
    finally:
        _advapi.CredFree(pcred)


def set_password(api: str, user: str, secret: str) -> None:
    """Guarda la contrasena; con secret vacio la borra."""
    key = cred_key(api, user)
    if not secret:
        _advapi.CredDeleteW(key, CRED_TYPE_GENERIC, 0)
        return
    blob = secret.encode("utf-16-le")
    buf = ctypes.create_string_buffer(blob, len(blob))
    cred = _CREDENTIAL(Type=CRED_TYPE_GENERIC, TargetName=key, UserName=str(user).strip(),
                       CredentialBlobSize=len(blob), CredentialBlob=ctypes.cast(buf, ctypes.POINTER(ctypes.c_char)),
                       Persist=CRED_PERSIST_LOCAL_MACHINE)
    if not _advapi.CredWriteW(ctypes.byref(cred), 0):
        raise OSError(f"CredWrite fallo ({ctypes.get_last_error()})")


# ---------------------------------------------------------------------------
# Migracion desde secrets.bin (DPAPI, clave = nombre de perfil)
# ---------------------------------------------------------------------------
class _Blob(ctypes.Structure):
    _fields_ = [("cbData", wt.DWORD), ("pbData", ctypes.POINTER(ctypes.c_char))]


def _unprotect(data: bytes) -> bytes:
    buf = ctypes.create_string_buffer(data, len(data))
    blob_in = _Blob(len(data), ctypes.cast(buf, ctypes.POINTER(ctypes.c_char)))
    out = _Blob()
    if not ctypes.windll.crypt32.CryptUnprotectData(ctypes.byref(blob_in), None, None, None, None, 0, ctypes.byref(out)):
        raise OSError("CryptUnprotectData fallo")
    try:
        return ctypes.string_at(out.pbData, out.cbData)
    finally:
        ctypes.windll.kernel32.LocalFree(out.pbData)


def migrate_legacy(profiles: list) -> int:
    """
    Pasa las contrasenas de secrets.bin al Administrador de credenciales, usando
    el api y el usuario de cada perfil. Solo una vez: despues renombra el archivo.
    No pisa una contrasena que ya este en el Administrador.
    """
    if not LEGACY_FILE.exists():
        return 0
    try:
        legacy = json.loads(_unprotect(LEGACY_FILE.read_bytes()).decode("utf-8"))
    except (OSError, ValueError):
        return 0
    moved = 0
    for p in profiles:
        secret = legacy.get(p.get("name"))
        if secret and p.get("api") and p.get("user") and not get_password(p["api"], p["user"]):
            set_password(p["api"], p["user"], secret)
            moved += 1
    LEGACY_FILE.rename(LEGACY_FILE.with_name("secrets.bin.migrated"))
    return moved
```
